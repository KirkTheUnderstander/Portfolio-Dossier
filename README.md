# Кирилл Лифанов — портфолио

[Открыть сайт](https://kirktheunderstander.github.io/Portfolio-Dossier/)

Статический сайт на HTML, CSS и JavaScript. Публикуется через GitHub Pages из корня ветки `main`; сборка и установка пакетов не требуются.

## Структура

- `index.html` — содержание и разметка.
- `assets/site.css` — стили и адаптивная сетка.
- `assets/site.js` — интро, навигация, вкладки и просмотр изображений.
- Изображения в корне — материалы портфолио и обложка для социальных сетей.
- `duolingo-english-test.pdf` — сертификат, доступный по ссылке в шапке.

Шрифты загружаются из Google Fonts. Прокрутка нативная, внешних JavaScript-библиотек нет. Основное содержание доступно при отключённом JavaScript; настройки уменьшения анимаций учитываются.

## Редактирование

При изменениях сохраняйте относительные пути к стилям, скрипту и материалам. Перед публикацией проверяйте мобильную версию, вкладки, просмотр изображений, меню и ссылку на сертификат. Резервные копии и экспорты для обзора не входят в публикуемую версию; предыдущие версии доступны в истории Git.

## Экспорт изображений

В Actions доступен ручной запуск **Export portfolio review**. Он снимает опубликованную страницу в Chromium, проверяет ширины 320–1440 px и сохраняет PNG всего сайта, читаемые фрагменты и состояния вкладок в артефакт `portfolio-gemini-review` на 30 дней. Инструменты экспорта устанавливаются только на CI и не загружаются посетителям сайта.
